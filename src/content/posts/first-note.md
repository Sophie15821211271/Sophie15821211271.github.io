## 从一个小例子开始

写笔记时，可以先记录问题，再用一小段代码验证自己的理解。

```python
def average(numbers):
    return sum(numbers) / len(numbers)

print(average([2, 4, 6]))
```

这篇示例可以在 Pages CMS 中编辑，也可以换成自己的第一篇笔记。
